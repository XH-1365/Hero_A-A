# ✨RoboMaster 英雄机器人控制库 (！！！下板程序内容)
## 项目简介
本项目是专为 RoboMaster 英雄机器人开发的嵌入式控制系统。采用 STM32F427IIHx 作为主控芯片，集成了底盘、云台、发射机构及裁判系统通信等功能。

## 🔥线序内容（A型开发板:主控: STM32F427IIHx）

    PG5	达妙拨盘		
    PG6	超级电容			
    PG7	底盘电机			
    PG8	电源			

# 🎭--废话简介内容---
## 1. 硬件环境
    主控: STM32F427IIHx

    通信接口:
    CAN: 用于电机驱动（大疆 6020、3508 电机等）及传感器数据读取
    USART: 用于 DR16 遥控器接收机、裁判系统交互及 Mini-PC 视觉通信
    I2C: 用于板载传感器读取

## 2. 核心功能模块
### 2.1 机器人控制应用 (application/)
chassis: 实现底盘运动控制，支持全向移动及底盘跟随/独立模式。

gimbal: 云台控制逻辑，集成 PID 算法及 IMU 数据融合，确保俯仰（Pitch）与偏航（Yaw）轴的高精度稳定。

shoot: 发射机构控制，包含拨弹电机和摩擦轮的协同逻辑。

robot_cmd: 统一调度遥控器、视觉系统指令，实现机器人状态机切换。

## 2.2 驱动与通信模块 (modules/)
电机驱动: 支持大疆（DJI）全系列电机及达妙（DM）电机控制。

传感器集成:

IMU (CH104): 通过 CAN/USART 接入，提供稳定的姿态反馈。

DTOF: 激光测距模块，用于距离感知。

裁判系统 (referee): 完整实现 RoboMaster 裁判系统协议，支持 UI 绘制与实时比赛数据获取。

## 3. 软件架构
底层: 基于 STM32 HAL 库，利用 DMA 提升大数据量通信效率。

算法: 集成标准 PID 控制算法及多种滤波器（如卡尔曼滤波、一阶低通滤波）。

实时性: 采用定时器中断与任务调度机制，确保各控制环路频率稳定。

## 4. 快速上手
### 4.1 环境配置
    IDE: Keil uVision5
    工具链: ARM Compiler 5/6

### 4.2 编译与下载
    使用 MDK-ARM/RM_Template.uvprojx 打开工程。
    配置调试器（如 ST-Link 或 J-Link）。
    点击编译并烧录至 STM32F427 开发板。
